## 🚀 Installation Instructions for Users

**Install v5.0.0:**

```bash
npm install -g leo-workflow-kit@5.0.0
```

**Automatic setup with all agents enabled:**

```bash
LEO_AUTO_INIT=true npm install -g leo-workflow-kit@5.0.0
```

**Verify installation:**

```bash
leo --version
# Output: 5.0.0

leo init
# All 6 agents pre-enabled and ready!
```
